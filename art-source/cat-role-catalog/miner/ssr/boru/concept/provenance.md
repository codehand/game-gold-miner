# Boru concept provenance — 2026-09-30

Original character concept generated using built-in `image_gen`, not CLI/API
fallback. Mica and Tobi's existing project sprites were visual-style references
only. Boru is a new calico excavator operator; exact prompts are retained here.

The solid-magenta first generation is preserved as `processed/raw-sheet.png`.
The generate2dsprite single-frame processing run passed geometric strict QC,
but visual inspection found magenta edging and erosion of the purple crystal.
Its `processed/single-1.png` is a rejected cleanup preview, NOT the delivery.

A built-in transparent-background edit removed the magenta background while
retaining the intentional purple crystal. The selected delivery is
`boru-excavator-concept.png`, copied unchanged from that tool output. It has
real alpha, but remains a static concept, not an animation or runtime asset.
The generated single-frame GIF is only a processor artifact, not authored motion.
